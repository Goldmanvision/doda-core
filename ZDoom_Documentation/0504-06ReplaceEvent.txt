ReplaceEvent

struct ReplaceEvent clearScope version("2.4");
The information for a StaticEventHandler.CheckReplacement event. You can mutate the variables in this event to change the result of replacement checking.

Instance Members
readOnly class<Actor> Replacee
The actor class which is being replaced.

class<Actor> Replacement
What to replace it with. This class type is already effected by skill and actor definition replacements, so it may be useful to read it. Modify this to change what the resulting replacement class ends up being.

bool IsFinal
If true, the engine will not attempt to continue going down the replacement chain, and will directly replace the actor with Replacement.

Overview of instance members
IsFinal, Replacee, Replacement
