# Generated Content Policy

Everything in this directory is generated by the DoDA Content Workbench.

Do not manually edit generated output.

Source data belongs in:

- `data_authoring/source/`
- `data_authoring/schemas/`

Generated content will eventually include:

- Native-readable structured data.
- UZDoom LANGUAGE fragments.
- MAPINFO include fragments.
- Narrow generated ZScript data declarations.
- Validation reports.
- Build manifests.
